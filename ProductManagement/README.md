# Ứng dụng quản lý sản phẩm - MVC

Bài tập Java Web Servlet + JSP theo kiến trúc MVC.

## Chức năng
- Hiển thị danh sách sản phẩm
- Thêm sản phẩm
- Sửa sản phẩm
- Xóa sản phẩm
- Xem chi tiết
- Tìm kiếm theo tên

## Công nghệ
- Java 8+
- Servlet 4.0
- JSP/JSTL
- Maven
- Tomcat 9

## Chạy
1. Mở project bằng IntelliJ IDEA.
2. Maven Reload/Load project.
3. Cấu hình Tomcat 9 và deploy file WAR `product-management`.
4. Truy cập: `http://localhost:8080/product-management/products`

Dữ liệu đang được lưu trong ArrayList để đúng yêu cầu giả lập ProductService, chưa dùng database.
